\begin{itemize}

  Code đã viết và build thành công.
\item
  Migration và seed cần thiết đã có.
\item
  Validation, ownership và authorization đã có.
\item
  Unit/integration/E2E test phù hợp đã pass.
\item
  Loading, empty, error, success và permission state đã có.
\item
  Log/audit cần thiết đã có và không lộ dữ liệu nhạy cảm.
\item
  Tài liệu và API contract được cập nhật.

  Chạy trên staging và đạt Acceptance Criteria.

  Không còn bug P0/P1 chưa có quyết định.
